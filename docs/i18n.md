# i18n & font (tiếng Nhật đã gỡ ở v0.17.0)

## Hệ thống

- 2 ngôn ngữ: 🇻🇳 vi (**mặc định**) / 🇬🇧 en. Tiếng Nhật đã gỡ hoàn toàn ở v0.17.0 (theo quyết định chủ web). Hệ tự viết, gọn:
  - Từ điển: `src/lib/messages.ts` (mỗi khóa `{ vi, en }`).
  - Provider + hook: `src/lib/i18n.tsx` (default locale `vi`, fallback `vi`).
  - Switcher ở góc phải navbar; lựa chọn lưu localStorage key `deal_locale` (chỉ nhận `vi`/`en`).
- `src/lib/labels.ts` chỉ còn formatter + key list — nhãn hiển thị đã chuyển hết vào `messages.ts`.

## Quy tắc khi thêm/sửa chuỗi UI

1. **Mọi chuỗi UI mới = thêm khóa vào `messages.ts` đủ CẢ 2 thứ tiếng vi/en** — không hardcode text trong component.
2. `/terms`, `/privacy` và **thông báo lỗi server (zod/ApiError)** giờ đều **tiếng Việt** (không còn ngoại lệ tiếng Nhật).
3. Ngoại lệ giữ nguyên: **tên thẻ trong catalog** (`card.nameJa`/`nameEn`) là DỮ LIỆU thật của thẻ Nhật, không phải UI — không dịch/không đụng.

## Font — KHÔNG ĐƯỢC BỎ

**Noto Sans** (next/font, subset `vietnamese` + `latin`) là font chính toàn trang; chữ Nhật fallback về Hiragino/Yu Gothic/Meiryo. Nếu bỏ Noto Sans sẽ **tái lỗi phông dấu tiếng Việt trên Windows** (đã fix ở 0.6.0).
