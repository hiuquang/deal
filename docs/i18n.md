# i18n & font (v0.6.0)

## Hệ thống

- 3 ngôn ngữ: 🇯🇵 ja (chính) / 🇻🇳 vi / 🇬🇧 en. Hệ tự viết, gọn:
  - Từ điển: `src/lib/messages.ts` (~170 khóa).
  - Provider + hook: `src/lib/i18n.tsx`.
  - Switcher ở góc phải navbar; lựa chọn lưu localStorage key `deal_locale`.
- `src/lib/labels.ts` chỉ còn formatter + key list — nhãn hiển thị đã chuyển hết vào `messages.ts`.

## Quy tắc khi thêm/sửa chuỗi UI

1. **Mọi chuỗi UI mới = thêm khóa vào `messages.ts` đủ CẢ 3 thứ tiếng** — không hardcode text trong component.
2. Ngoại lệ có chủ đích, **giữ nguyên tiếng Nhật**:
   - `/terms`, `/privacy` (bản pháp lý gốc);
   - thông báo lỗi từ server (zod/ApiError);
   - tên thẻ trong catalog (là dữ liệu, không phải UI).

## Font — KHÔNG ĐƯỢC BỎ

**Noto Sans** (next/font, subset `vietnamese` + `latin`) là font chính toàn trang; chữ Nhật fallback về Hiragino/Yu Gothic/Meiryo. Nếu bỏ Noto Sans sẽ **tái lỗi phông dấu tiếng Việt trên Windows** (đã fix ở 0.6.0).
